# MateDrive Continuous Product Readiness

Updated: 2026-07-28

## Long-term goal

Keep MateDrive safe to publish, fast to open, accurate with incomplete TeslaMate data, and understandable without setup expertise. Repeat this review after every meaningful product change until the project owner explicitly stops the project.

## Release decision

A build is eligible for TestFlight only when all P0 and P1 items below are closed. App Store submission additionally requires the real review server integration gate and a completed manual pass on a physical iPhone.

## Gates

### P0: submission blockers

- The app and widget build with the release version and build number.
- The full automated suite has zero failures.
- App Store, independent-release, privacy, localization, tariff, and archive audits pass.
- No credentials, precise fixture locations, private server addresses, or vehicle artwork ship in source or release assets.
- The app launches without a crash and cached content remains usable while the server is unavailable.

### P1: product correctness

- Missing values remain visibly unknown; they are never converted to zero.
- Short drive and charge visibility follows the user setting.
- Saved and automatically detected journeys coexist without duplicates.
- Unknown future settings values degrade safely instead of making all settings unreadable.
- Charge price estimates state their source and confidence, and user corrections always take precedence.
- Battery health distinguishes measured retention from an absolute health estimate.
- Every list and detail page opens from cache; network refresh happens in the background.
- Map interaction, playback, and chart rendering do not block scrolling or navigation.

### P1: real integration

- Run `make review-integration-test` against the exact server profile intended for App Review.
- Verify vehicles, status, drives, charges, costs, battery, software, activities, pagination, and global settings.
- Repeat once with the server unreachable to verify offline behavior and recovery.
- Confirm that the App Review account can reach the server outside the owner's private network.

### P1: manual UI and accessibility

- Check Home, Activity, Features, Settings, drive detail, charge detail, maps, charts, backup, and empty/error states.
- Check Simplified Chinese, Traditional Chinese, and English.
- Check light and dark appearance, larger text sizes, VoiceOver labels, Reduce Motion, and landscape where supported.
- Check tap targets, bottom-bar overlap, keyboard avoidance, loading placeholders, and destructive-action confirmation.

### P2: post-launch hardening

- Capture launch and navigation signposts on a physical iPhone and establish device-specific baselines before enforcing launch thresholds.
- Expand languages only when every supported screen and widget has complete translations.
