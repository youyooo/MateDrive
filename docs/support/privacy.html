MateDrive 隐私政策

更新日期：2026 年 7 月 28 日

概述

MateDrive 是用户自行配置的 TeslaMate API 只读客户端。MateDrive 开发者不运营接收车辆数据的后端服务。

应用处理的数据

应用可能展示配置服务器提供的车辆状态、充电记录、行程路线、位置、软件版本、电池估算、手工费用和本地偏好。MateDrive 不要求或保存 Tesla 账号密码。

本地存储

服务器设置和应用偏好保存在设备上，认证密钥保存在 Apple Keychain。按服务器和车辆隔离的 Widget 快照、离线首页快照、完整活动时间线和只读 API 响应缓存保留在应用沙盒中。相邻行程合并仅在设备上改变列表显示，依据缓存记录中的时间、坐标或地址进行判断，不会合并、修改或删除 TeslaMate 原始记录。Widget 车辆标识、活动缓存键和 API 缓存文件名使用单向哈希，不会明文保存服务器地址、车辆编号或认证头；缓存文件使用 iOS 数据保护并设有有效期或容量上限。用户可在设置的“隐私与本地数据”中查看并清除这些缓存。

可选 iCloud 备份

用户明确开启后，MateDrive 可将本地数据库和非敏感应用设置保存到用户自己的 iCloud 私人数据库，并最多保留最近三份成功备份。备份可能包含车辆状态、充电、行程、路线、位置标签、费用规则和电池分析等本地记录。服务器密码、令牌、API 密钥及其他 Apple Keychain 内容不会上传，也不会从备份恢复。用户可随时关闭自动备份、删除单份或全部云端备份。恢复前应用会先创建本地安全快照，并在失败时自动回滚。

Optional iCloud backup is opt-in and stores the local database plus non-secret settings in the user's private CloudKit database. Keychain passwords, tokens, and API keys are excluded. MateDrive keeps at most the three newest successful backups and lets the user delete one or all backups.

分享图片

单次行程、周期回顾、电池报告、成就卡片和多行程路程报告图片完全在设备上生成，MateDrive 不会将图片上传到开发者服务器。路程报告不使用自定义路程名，并默认隐藏精确日期、起点和终点、路线轮廓与费用；周期回顾默认隐藏精确活动日期和充电、停车费用；电池报告默认隐藏精确记录日期和开始记录时里程，并明确区分整车寿命健康度与 TeslaMate 记录期保持率；成就卡片默认隐藏解锁日期、地点名称和进度细节，且不会包含原始坐标或关联行程编号。用户主动启用可选字段时，应用会在分享前显示隐私提醒。图片只有在用户调用 iOS 系统分享功能后，才会交给用户选择的目标应用或服务。

外部服务

使用相关功能时，地图和地理编码由 Apple 服务处理。路线天气默认关闭。只有用户在行程详情中明确启用后，应用才会将一个代表性的精确路线坐标和行程时间发送给 Open-Meteo，以返回相应位置的天气样本；不会发送整条行程轨迹。Open-Meteo 的隐私条款说明，其用于故障排查的服务器日志可能包含坐标和 IP 地址，最长保留 90 天；Open-Meteo 声明不会将这些日志关联到用户身份、用于广告跟踪或分享给第三方。MateDrive 开发者无法访问这些日志，也不使用广告追踪器或开发者分析服务。

Route weather is off by default. After the user explicitly enables it, MateDrive sends one representative precise route coordinate and the drive time to Open-Meteo for app functionality; it does not send the complete route. Open-Meteo states that request logs may contain coordinates and IP addresses, are retained for up to 90 days, are not linked to user identities, and are not used for advertising tracking. MateDrive does not use advertising trackers or developer analytics.

控制与删除

用户可在 MateDrive 设置中随时关闭路线天气以停止后续 Open-Meteo 请求，并可单独清除本机保存的路线天气。用户还可清除离线首页、活动时间线与 Widget 车辆快照，并可单独清除 API 响应缓存；也可通过删除应用移除全部本地数据。删除应用不会自动删除已选择保存到私人 iCloud 数据库的备份，用户应先在“iCloud 备份”页面删除这些备份。清除缓存或云端备份不会删除 Apple Keychain 中的认证密钥或 TeslaMate 服务器数据。TeslaMate 服务器中的数据由用户在自己的服务器上管理。

联系

隐私问题可通过 GitHub Issues反馈；安全漏洞请使用 私密安全报告。请勿公开认证信息、VIN、精确位置或行程轨迹。返回支持页。
