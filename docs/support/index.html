MateDrive 用户支持

面向 iPhone 的原生只读 TeslaMate 数据客户端。

连接 TeslaMate

打开 MateDrive 设置，输入 TeslaMate API 的 HTTPS 地址，选择服务器配置的认证方式，然后运行“测试连接”。

MateDrive 只连接用户配置的服务器，不接受 Tesla 账号凭据，也不会向车辆发送控制命令。

连接排查

  • 确认 iPhone 能直接访问 API 地址。
  • 在诊断报告中确认 API 版本和认证方式。
  • 互联网服务应使用可信 HTTPS 证书。
  • 确认 API 能读取车辆、状态、行程、充电和全局设置。

数据准确性

MateDrive 展示 TeslaMate 已记录的数据，并明确标记缺失样本，不用零值代替缺失值。电池健康估算取决于历史数据质量和车辆容量校准。

隐私

请阅读 MateDrive 隐私政策。

Read-only operation

MateDrive reads data from the TeslaMate API you configure and does not send commands to your vehicle.
