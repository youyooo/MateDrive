## 宣传文本

原生连接你的 TeslaMate，在 iPhone 上流畅查看电量、行程、充电费用、电池健康、活动分析、小组件和只读提醒。

## 描述

MateDrive 是一款为 TeslaMate 用户设计的独立原生 iOS 客户端。连接你自己的 TeslaMate API 服务器，即可在 iPhone 上查看车辆状态、充电记录、行程、里程、电池健康、活动与统计数据。

MateDrive 采用缓存优先的交互方式。已有数据会立即显示，网络刷新和历史同步在后台继续进行。服务器配置保存在设备本地，认证密钥存储在 Apple Keychain 中；MateDrive 不运营车辆数据中转服务，也不收集开发者分析数据。

主要功能：

• 车辆概览：圆形电量或表显续航、胎压、地图、最近行程、最近充电费用和总里程。
• 充电分析：单笔费用修正、地区与分时电价规则、交流/直流对比、功率曲线、费用覆盖率和汇总统计。
• 行程分析：路线地图、速度、功率、海拔、能耗效率、可用时的路线天气，以及多行程比较。
• 智能活动：在设备上进行地点围栏识别、通勤建议、活动分类、休眠汇总、行程检测和自定义标签。
• 电池与历史：里程、统计、软件更新、电池健康趋势、数据质量提示，以及隐私安全的本地报告分享。
• iOS 功能：每辆车独立配置的主屏幕小组件、本地只读提醒，以及 Siri、Spotlight 和快捷指令入口。
• 区域设置：自动或手动选择 ISO 货币，并可独立选择 TeslaMate、公制或英制单位。
• 首发语言：简体中文、繁体中文和英语。
• 可选私人 iCloud 备份：用户明确同意后备份本地数据库和非敏感设置；Keychain 认证密钥不会进入备份。

MateDrive 只读取数据，不控制车辆。它不会解锁、启动车辆、移动车辆、开始充电、鸣笛、闪灯，也不会向 Tesla 账号或车辆发送控制指令。

使用本 App 前，需要自行部署可访问的 TeslaMate API 服务。MateDrive 是独立开发的非官方 iOS App，与 Tesla, Inc.、TeslaMate 或其他服务提供商不存在隶属、赞助或官方授权关系。相关产品名称仅用于说明兼容性，商标归各自权利人所有。

## 审核备注

MateDrive 需要审核员在“设置”中配置一个可访问的 TeslaMate API 服务器。审核时请使用公开的 MateDrive 合成测试接口：

- TeslaMate API 地址：`https://youyooo.github.io/MateDrive/review-demo`
- 认证方式：无
- 用户名、密码和 Token：全部留空

该接口只提供每天更新的合成只读数据，不包含真实用户、VIN、账号凭据、私人服务器地址或真实路线。正式 App 不内置该地址，普通用户只连接自己配置的 TeslaMate 服务。
