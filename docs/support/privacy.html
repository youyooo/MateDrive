MateDrive 隐私政策

更新日期：2026 年 7 月 12 日

概述

MateDrive 是用户自行配置的 TeslaMate API 只读客户端。MateDrive 开发者不运营接收车辆数据的后端服务。

应用处理的数据

应用可能展示配置服务器提供的车辆状态、充电记录、行程路线、位置、软件版本、电池估算、手工费用和本地偏好。MateDrive 不要求或保存 Tesla 账号密码。

本地存储

服务器设置和应用偏好保存在设备上，认证密钥保存在 Apple Keychain。Widget 和离线首页快照保留在设备上，可在设置中清除。

外部服务

使用相关功能时，地图和地理编码由 Apple 服务处理；路线天气功能会向 Open-Meteo 发送所选坐标与时间。MateDrive 不使用广告追踪器或开发者分析服务。

控制与删除

用户可在 MateDrive 设置中清除本地快照和应用数据，也可通过删除应用移除本地数据。TeslaMate 服务器中的数据由用户在自己的服务器上管理。

联系

隐私问题可通过 GitHub Issues反馈；安全漏洞请使用 私密安全报告。请勿公开认证信息、VIN、精确位置或行程轨迹。返回支持页。
